# Instagram Product Dissection

##  Project Overview
This project focuses on dissecting the Instagram platform to understand how its core features are supported by an efficient database schema and ER diagram.

The objective of this project is to analyze Instagram’s functionalities, identify real-world problems it solves, and design a scalable schema that represents users, posts, likes, comments, and followers.

---

##  Key Features Analyzed
- User Profiles
- Photo & Video Posts
- Likes and Comments
- Followers & Following
- Hashtags
- Content Discovery (Explore)

---

##  Problem Statement
Social media platforms like Instagram handle millions of users and interactions daily. This project demonstrates how proper schema design helps manage such large-scale data efficiently.
